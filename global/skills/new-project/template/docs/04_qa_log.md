# Q&A ログ

相談内容・質問・回答・決定事項を時系列で残す。新しいものを下に追記する。

記入形式:

```markdown
## Q-XXX: 件名（YYYY-MM-DD）

- **質問/相談**: …
- **回答/検討**: …
- **決定**: …（未決なら「未決」）
- **反映先**: 更新したドキュメントへのリンク
```
